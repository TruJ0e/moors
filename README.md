# The Moors

A single-file Three.js experience: a lone walker crossing the Yorkshire Moors at night — procedural heightmap terrain, moonlight and low mist, dry-stone walls, gnarled trees, standing stones, synthesized wind and distant eerie sounds. Everything procedural; the only network fetch is the pinned Three.js module.

Built by a three-model relay — Muse, GPT and Gemini — over 100 planning rounds, 100 build rounds, a test rotation and a final review round, per Truman Hensley's commission. The plan and its evolution live in PLAN.md; the game is moors.html (open it in a desktop browser, click to begin).
